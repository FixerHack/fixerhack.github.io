TG-botFarm

// Telegram магазин цифрових товарів

Повнофункціональний асинхронний Telegram-бот для автоматизованого продажу цифрових товарів. Покупець отримує товар миттєво після оплати. Адміністратор керує всім прямо з Telegram без додаткових інструментів.

Функціонал

🛒 Каталог товарів

Категорії в 2 колонки, одиночні товари з 🔥, картка з ціною та залишком (🟢/🟡/🔴). Товари з нульовим залишком помічаються 🚫.

💳 Оплата через CryptoBot

Покупець вводить промокод або пропускає → бот створює інвойс → оплата → автоматична видача товару після перевірки статусу.

⚛️ Атомарна видача

BEGIN IMMEDIATE → SELECT + DELETE → COMMIT. При одночасних натисканнях від 10 користувачів — кожен отримає унікальний товар без дублювань.

🎟 Промокоди

Знижка в %, ліміт використань, дата закінчення. При 100% знижці — товар видається миттєво без інвойсу. Один користувач не може використати промокод двічі.

🔗 Реферальна система

+$0.50 за кожного нового реферала. Кожні 2 реферали з покупкою = +1% знижки (максимум 20%). Вмикається/вимикається адміністратором.

👨‍💻 FSM Адмін-панель

Додавання товарів, категорій, промокодів через FSM-діалог. Розсилка, статистика, управління юзерами — бан, видача, анулювання аккаунту.
