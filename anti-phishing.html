Anti-Phishing Guard

// Chrome Extension · Manifest V3 · Security

Розширення для браузера (Manifest V3), яке виявляє фішингові сторінки що імітують інтерфейс Telegram і показує повноекранне попередження. Аналіз URL, ключових слів та полів вводу в реальному часі.

Як працює

🔍Аналіз hostname

Виявлення типових опечаток та підозрілих патернів у доменному імені. Офіційні домени Telegram (telegram.org, t.me, web.telegram.org) автоматично виключаються.

📝Аналіз вмісту

Пошук ключових слів пов'язаних з Telegram у тексті сторінки. Виявлення форм вводу для телефону, коду підтвердження та пароля.

🚨Попередження

Повноекранне попередження з кнопками «Покинути сайт» або «Продовжити (небезпечно)». Інжектується через content.js на всі підозрілі сторінки.

⚙️Налаштування

Вмикання/вимикання через popup.html. Вибір мови інтерфейсу (UK/EN). Всі налаштування зберігаються в chrome.storage.sync між сесіями.

Файли розширення

manifest.json Опис розширення MV3. Права: activeTab, scripting, storage, host_permissions: <all_urls>
background.js Service worker — ініціалізує початкові налаштування (enabled = true, language = 'uk')
content.js Основна логіка виявлення фішингу та UI повноекранного попередження
popup.html Інтерфейс налаштувань (вмикання, вибір мови)
popup.js Логіка взаємодії з chrome.storage для збереження/завантаження налаштувань
