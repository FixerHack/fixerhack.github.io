Фази розробки

1
Чистий агент на VPS ✓ Готово

Реінсталяція системи на VPS. Мінімальний набір інструментів Kali. Чиста установка OpenClaw. Підключення моделі та Telegram. Перевірка що термінальні команди виконуються.

OpenClaw Kali Linux Telegram Bot systemd
2
Особистість Kitty ✓ Готово

AGENTS.md з правилами. System prompt з характером та стилем відповідей. Логіка форматування під HUD. Скіли з ClawHub. Herbie — субагент виключно для Wi-Fi / handshake задач.

SOUL.md ClawHub skills Herbie sub-agent HUD formatting
3
Голос ✓ Готово

IndexTTS2 на VPS. Клонований голос Kitty. Гібридна логіка: локальні WAV-файли на Android + генерація на VPS для унікальних фраз.

IndexTTS2 Piper fallback WAV assets SoundManager.kt
4
Android + Прошивка ⚡ Зараз

Єдиний Android-додаток: BLE з годинником та навушниками, Node.js HTTP-проксі всередині, HUD на окуляри через Presentation API, аудіо з T-Watch S3 → VPS → голос Kitty в навушники. Прошивка Bruce fork на LilyGo T-Watch S3 (ESP32-S3): watchface як головний екран, double-tap → Kitty, Glasses HUD секція.

T-Watch S3 Bruce fork ESP32-S3 BLE Kotlin stark_proxy.js Presentation API
5
HUD і OpSec Попереду

Кольоровий інтерфейс в окулярах. Ghost/Burn режими. Watchdog HUD. Карта Wi-Fi мереж від Herbie. Повна операційна безпека екосистеми.

Ghost Mode Burn Mode Watchdog Network Map OpSec

Агенти OpenClaw

🐱
Kitty
Головний AI-асистент. Характер, голос, HUD-форматування. Оркеструє всіх субагентів.
👻
Ghost
OSINT агент. Збір відкритих даних, розвідка цілей, аналіз публічної інформації.
📡
Pulse
Nmap-сканування. Мережева розвідка, виявлення хостів та відкритих портів.
🔐
Cipher
Зламування хешів. Словникові та брутфорс атаки на перехоплені handshake-и.
🐕
Watchdog
System HUD. HTML-звіти в Telegram, моніторинг стану VPS в реальному часі.
🔭
Oracle
Research pipeline. Пошук через Tavily + Scrapling, синтез інформації з мережі.
📶
Herbie
Wi-Fi / handshake субагент. Виключно бездротова розвідка та захоплення трафіку.
