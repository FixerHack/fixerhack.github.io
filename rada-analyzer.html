Аналіз Законопроєктів

// Верховна Рада · AI · Google Gemini · Cloud Run

Автоматизована система для завантаження, обробки та AI-аналізу законопроєктів з сайту Верховної Ради України. Виявляє корупційні ризики, конвертує PDF/DOCX у Markdown, зберігає у Firestore. Telegram бот + REST API.

Автоматичний пайплайн

1
📥 Завантаження HTML-картки

Скрейпінг сторінки законопроєкту з rada.gov.ua. Підтримка діапазонів сторінок та лічильника.

2
📄 Завантаження документів

Автоматичне завантаження прикріплених PDF та DOCX файлів із картки законопроєкту.

3
🔄 Конвертація у Markdown

PDF → Markdown через pdfplumber/pdfminer. DOCX → Markdown через pypandoc. Структурований текст для AI.

4
🤖 AI-аналіз через Gemini

Аналіз змісту, виявлення корупційних ризиків, структурований звіт. Затримка 2 секунди між запитами (ліміти API).
