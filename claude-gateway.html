Про проект

Окремий інструмент, що перетворює Claude Code на сервері на сервіс: власний HTTP API (/v1/complete), OpenAI-сумісний (/v1/chat/completions), Anthropic-сумісний (/v1/messages) та MCP-сервер з інструментом ask_claude.

Кожен запит виконується як окремий виклик claude -p — без інструментів, без збереження сесії, у порожній тимчасовій теці. Тобто Claude Code працює суто як модель; відповідь можна отримати за JSON-схемою.

Ключові можливості[ 6 ]

Власний HTTP API

POST /v1/complete з опційним JSON за схемою.

OpenAI-сумісний

Готові клієнти й SDK OpenAI працюють без змін.

Anthropic-сумісний

POST /v1/messages під SDK Anthropic.

MCP-сервер

Інструмент ask_claude через HTTP (/mcp) або stdio.

Ізоляція запитів

Без інструментів, без сесії, у тимчасовій теці.

Токен-авторизація

Кожен запит потребує Bearer або x-api-key.
