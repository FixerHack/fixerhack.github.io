Lester Bot

// Discord Moderation Bot + Web Dashboard

Повноцінний бот модерації для Discord-серверів з веб-панеллю. Написаний на Python 3.11, discord.py 2.x, FastAPI + SQLite. Ліцензійна активація (SaaS), мультимовність та повний набір інструментів модерації.

Функціонал

🔑Ліцензійна активація

Бот не запускається без активації. Пробний тиждень (7 днів, 1 раз), або ввести ключ. Власник бота керує ключами через DM: /license create monthly 10.

🛡️Модерація

/warn /kick /ban (з таймером) /unban /mute /unmute. Картка учасника з повною історією. Захист власника сервера. Ієрархічна перевірка прав.

🎫Тікети та репорти

/ticket open/close — приватний канал тікету. /ticket add @user — додати учасника. /report @user reason — скарга в мод-канал з кнопками прийнято/відхилено.

📢Система оголошень

Заплановані оголошення з точністю до хвилини. Час у часовому поясі сервера (Europe/Kyiv). Перевірка по чорному списку. Ліміт 3 оголошення на юзера.

🔐GTA Верифікація

4-кроковий процес: правила → нік → платформа → модератор. Платформи: PS4, PS5, Xbox, PC-Legacy, PC-Enhanced. Заявки у веб-панелі та Discord.

🌐Веб-панель

Дашборд, користувачі, лог модерації, чорний список, заявки, налаштування, Swagger UI. Доступна на localhost:8000 після /setup auto.
