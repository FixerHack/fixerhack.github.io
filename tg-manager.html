TG-Manager

// Complete Bot Management System

Повна система керування Telegram ботами з трьома компонентами: FastAPI backend з JWT автентифікацією, React frontend з темною темою та aiogram Telegram-бот з модульною архітектурою (23 файли).

Компоненти системи

🔧
Backend (FastAPI)
  • Модульна REST API
  • JWT автентифікація
  • Управління ботами та акаунтами
  • Запуск/зупинка ботів
  • Конвертер сесій (.session ↔ .txt)
  • Swagger документація /docs
🌐
Frontend (React)
  • Адаптивний інтерфейс
  • Панель керування ботами
  • Управління акаунтами
  • Налаштування та статистика
  • Темна тема (cyberpunk)
  • Real-time оновлення
🤖
Telegram Bot (aiogram)
  • Повний функціонал Web панелі
  • Модульна архітектура (23 файли)
  • Кнопки в 2 ряди (компактний UI)
  • FSM діалоги
  • Створення/керування ботами
  • Автоматичний перезапуск

API Endpoints

POST /api/auth/login
JWT автентифікація — повертає токен, username, is_root
POST /api/bots/create
Створення нового бота (auth_bot, spam_bot, custom)
GET /api/bots/list_user
Список ботів користувача зі статусами
POST /api/bots/start_user
Запуск бота в реальному часі
DELETE /api/accounts/delete
Видалення акаунту з підтвердженням
