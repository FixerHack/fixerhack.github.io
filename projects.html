MacUtil

Open-source

Безкоштовний cleaner, оптимізатор і аналізатор безпеки для macOS у дусі CleanMyMac, OnyX та інструментів Objective-See. Нативний Swift/SwiftUI, без телеметрії та підписок, з Homebrew-встановленням.

Swift SwiftUI macOS Security Homebrew GPL-3.0

Telegram Anti-Phishing Guard

Open-source

Chrome-розширення (Manifest V3), що виявляє фішингові сторінки, які імітують Telegram. Аналіз hostname на тайпсквотинг, пошук ключових слів і полів вводу з повноекранним попередженням.

JavaScript Chrome Extension Manifest V3 Anti-Phishing

Tension Index

Open-source

OSINT-моніторинг сигналів ескалації для 38 країн Європи за шкалою 0–10. Щодня збирає офіційні travel advisories, порівнює версії, класифікує зміни через LLM і повідомляє, скільки незалежних джерел це підтверджують. Telegram-бот + публічна карта.

Python aiogram 3 OSINT SQLite LLM

UserTGBot Platform

Open-source

Платформа Telegram-userbot із незалежно розгортуваних сервісів на спільній Postgres-схемі. Тарифи й оплати (Telegram Stars, Crypto Pay), прив'язка акаунтів через інлайн-пад, Fernet-шифрування сесій, адмін-панель і фід змінених/видалених повідомлень.

Python Telethon FastAPI PostgreSQL Fernet Encryption Docker

claude-gateway

Open-source

Перетворює Claude Code на сервері на сервіс для будь-яких програм: власний HTTP API, OpenAI- та Anthropic-сумісні ендпоінти і MCP-сервер. Кожен запит ізольований — без інструментів, без сесії, у тимчасовій теці. Токен-авторизація, systemd-розгортання.

Python API Gateway MCP systemd

React FastAPI aiogram JWT Pyrogram

Python FastAPI Gemini AI Firestore Google Cloud
